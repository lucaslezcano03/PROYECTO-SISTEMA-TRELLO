# Fundamentación del proyecto

Elegimos este proyecto porque está basado en una experiencia real dentro del área de soporte técnico, donde se gestionan tickets e incidencias de clientes mediante distintas etapas de seguimiento y resolución.

El objetivo es desarrollar un sistema que permita organizar y administrar tareas técnicas de manera clara y ordenada, facilitando la asignación, seguimiento y control de cada caso.

El sistema estará orientado a técnicos que reciben tickets, los clasifican según su estado y pueden registrar el avance hasta llegar a una solución.
