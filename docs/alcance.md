# Alcance inicial del sistema

El sistema permitirá gestionar tickets técnicos mediante tableros, columnas y tarjetas.

Cada ticket representará un caso o incidencia de un cliente. Los tickets podrán organizarse en estados como Nuevo, En seguimiento, Pendiente y Solucionado.

En una primera etapa se desarrollarán funciones básicas como creación de tableros, creación de tickets, asignación de responsables y cambio de estado.
